# For-loop
```run-java
public class loops {  
    public static void main(String[] args){ 
	    for (int i = 0; i < 10; i++){
		    System.out.println(i);
	    }
    }  
}
```

# While-loop
```run-java
public class loops {  
    public static void main(String[] args){ 
	    int i = 10;
	    while (i>0){
			System.out.println(i);
			i--;
	    }
    }  
}
```
# Recursion
```run-java

    public static void main(String[] args){ 
	    countDown(10);
```
