# If, else and switch 
```run-java
public class Main {
	public static void main(String[] args){
		int dayOfWeek = 5;
		
		if (dayOfWeek == 7 || dayOfWeek == 6){
			dance(1);
		} else if (dayOfWeek == 5){
			dance(2);
		} else {
			dance(3);
		}
	}
	public static void dance(int day){
		switch (day) {
			case 1:
				System.out.println("Twerk");
				break;
			case 2:
				System.out.println("Almost...");
				break;
			case 3:
				System.out.println("No dance :(");
				break;
		}
	}
}
```


# Ternary operations
Returns true if a statement is correct else false..
```run-java
public class Main {
	public static void main(String[] args){
		int age = 20;
		
		System.out.println(driver(age));
	}
	public static boolean driver(int age){
		boolean hasDrivers = false;
		return hasDrivers ? age > 18 : false; // true if age > 18 else false.
	}
}

```
