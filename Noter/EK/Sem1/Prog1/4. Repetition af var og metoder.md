# Overloading
This is an example of function overloading:

```run-java
public class Overloading {
	public static void main(String[] args){
		//int
		System.out.println(add(5,5));
		System.out.println(add(5,5,5));
		//double
		System.out.println(add(5.0,5.0));
		System.out.println(add(5.0,5.0,5.0));
	}
	public static int add(int a, int b){
		return a + b;
	}
	public static int add(int a, int b, int c){
		return a + b + c;
	}
	public static double add(double a, double b){
		return a + b;
	}
	public static double add(double a, double b, double c){
		return a + b + c;
	}
}
```
In short you are able to create functions of the same name with a different amount of parameters. This can be useful for **functions that take an undefined amount of parameters**, like addition, and **functions that can take different types of parameters** (you can also change the **order of the parameters**). 

# Print formatting

```run-java
public class Main {
	public static void main(String[] args){
		System.out.printf("%d\n", 10); //int
		System.out.printf("%,d\n", 1000); //int with comma
		System.out.printf("%f\n", 10.000001); //float and double
		System.out.printf("%.1f\n", 10.000001);
		System.out.printf("%c\n", 'a'); //char
		System.out.printf("%C\n", 'a'); //char caps
		System.out.printf("%s\n", "hello"); //string
		System.out.printf("%S\n", "hello"); //string caps
		System.out.printf("%b\n", 5<4); //boolean
		System.out.printf("%B\n", 5<4); //boolean caps
		System.out.printf("%x\n", 10); //int in base 16 (hex)
		//System.out.printf("%b\n", "lol");
		
		int testInt = 00001;
		System.out.printf("%05d\n", testInt); //padded with zeros at least 8 digits
	}
}
```
