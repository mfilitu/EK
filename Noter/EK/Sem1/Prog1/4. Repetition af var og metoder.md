# Overloading
This is an example of function overloading:

```run-java
public class Overloading {
	public static void main(String[] args){
		//int
		System.out.println(add(5,5));
		System.out.println(add(5,5,5));
		//double
		System.out.println(add(5.0,5.0));
		System.out.println(add(5.0,5.0,5.0));
	}
	public static int add(int a, int b){
		return a + b;
	}
	public static int add(int a, int b, int c){
		return a + b + c;
	}
	public static double add(double a, double b){
		return a + b;
	}
	public static double add(double a, double b, double c){
		return a + b + c;
	}
}
```
In short you are able to create functions of the same name with a different amount of parameters. This can be useful for **functions that take an undefined amount of parameters**, like addition, and **functions that can take different types of parameters** (you can also change the **order of the parameters**).
