## Creating arrays:
```run-java
public class array {  
    public static void main(String[] args){ 
	    int[] A = new int[4]; //Empty array of 4 elements
	    int[] B = {1,2,3,4}; //Non-empty array of 4 elements
	    
	    System.out.println("The zeroth element is " + A[0]);
	    System.out.println("The first element is " + A[1]);
	    
	    System.out.println("The zeroth element is " + B[0]);
	    System.out.println("The first element is " + B[1]);
    }  
}
```

## Displaying Arrays
```run-java
import java.util.Arrays;

public class array {  
    public static void main(String[] args){ 
	    int[] a = {1, 2, 3, 4};
	    
	    System.out.println("Displays the address of the array in memory");
		System.out.println(a); 
		System.out.println();
		
		System.out.println("This prints the whole array");
		printArray(a);
		System.out.println();System.out.println(); //Dont look here pls
		
		System.out.println("We can also use the \"Arrays\" import");
		System.out.println(Arrays.toString(a));
	    
    }
    
    public static void printArray(int[] a){
	    int count = 0;
	    for (int i = 0; i<a.length; i++){
		    System.out.print(a[i]+ " ");
		    count++;
	    }
	    System.out.println("\nlength of array is: " + count);
    }
}
```

## Copying Arrays
Since array variables contain only the reference to the array, when assigning a new variable to an existing array it just copies the reference and not the array itself.

```java
double[] a = new double[3];
double[] b = a;
```

![[Pasted image 20260217123343.png]]

Any changes made to array ==a== will be displayed by array ==b==. This is because ==a== and ==b== are different names for the same array. Sometimes called **aliases**.

If we actually want to copy an array we need to create a new array and copy it like this:
```run-java
public class array {  
    public static void main(String[] args){ 
	    int[] A = {1,2,3,4};
	    int[] B = new int[4];
	    
	    System.out.println("before copy:");
	    printArray(A);
	    System.out.println();
	    printArray(B);
	    
	    copyArray(A, B);
	    System.out.println("After copy:");
	    printArray(A);
	    System.out.println();
	    printArray(B);
	    
    }
	public static void printArray(int[] a){
	    int count = 0;
	    for (int i = 0; i<a.length; i++){
		    System.out.print(a[i]+ " ");
		    count++;
	    }
	    System.out.println("\nlength of array is: " + count);
    }
    
    public static int[] copyArray(int[] a, int[] b){
	    for (int i = 0; i<a.length; i++){
		    b[i] = a[i];
	    }
	    return b;
    }
}
```

Or use the java.util.Arrays import: 
```java
int[] b = Arrays.copyOf(a, 4);
```


## The Enhanced for loop (for each)

Since traversing arrays is so common, Java provides an alternative syntax that makes the code more compact. Consider a `for` loop that displays the elements of an array on separate lines:

```java
for (int i = 0; i < values.length; i++) {
    int value = values[i];
    System.out.println(value);
}
```

We could rewrite the loop like this:

```java
for (int value : values) {
    System.out.println(value);
}
```

This statement is called an **enhanced for loop**, also known as the “for each” loop. You can read the code as, “for each `value` in `values`”. It’s conventional to use plural nouns for array variables and singular nouns for element variables.

### Example

```run-java
import java.util.Random;

public class array {  
    public static void main(String[] args){ 
	    int[] scores = randomArray(100);
	    
	    int[] counts = new int[100];
	    
	    for (int score : scores){
		    counts[score]++;
	    }
	    
	    printArray(counts);
	    
    }
    
    public static int[] randomArray(int size) {
	    Random random = new Random(60);
	    int[] a = new int[size];
	    for (int i = 0; i < a.length; i++) {
	        a[i] = random.nextInt(100);
	    }
	    return a;
	} 
	public static void printArray(int[] a){
		System.out.print("{"+a[0]);
	    for (int value : a){
		    System.out.print(", "+a[value]);
	    }
	    System.out.print("}");
    }
}
```
